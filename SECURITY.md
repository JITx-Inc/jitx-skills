# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in JITX Skills, please report it
privately so we can address it before public disclosure.

- Email **support@jitx.com** with the subject line `Security — jitx-skills`.
- Include a description, reproduction steps, the affected version, and any
  relevant logs or proof-of-concept.

Please do **not** open a public GitHub issue for security vulnerabilities.

## Supported Versions

The most recently released version of `jitx-skills` receives security updates.

## Response

We aim to acknowledge reports within a few business days and will keep you
informed of remediation progress.
